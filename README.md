# Role-Playing Game Management System

## Background

The project is a software system for managing a role-playing game.
The system is designed to help players and the Game Master (GM) organize
and manage game sessions. At the moment, game information can be difficult
to manage when it is shared through messages or written notes.

The purpose of this project is to create a simple system where players and
the GM can manage important game information in one place.

## Introduction

The Role-Playing Game Management System allows players to participate in game sessions and allows the Game Master to manage the game.

Players can use the system to access information about their characters and game sessions. The GM can manage sessions and provide information to the players.

The system will be developed as a software engineering project. The requirements described in this document are the initial requirements and may be changed or extended during the development of the project.
